# Restaurant Plan Editor

Single-file 2D floor-plan editor and synced 3D model for a food-service facility (schematic, not a construction document).

- Open `index.html` in a modern browser. No build step, no server.
- 3D view loads Three.js 0.160.0 from jsDelivr (internet required).
- Plans are saved only in your browser (localStorage). Use **JSON** to export a backup.

## محرر مخطط المطعم
ملف واحد يعمل مباشرة في المتصفح. المخطط توضيحي وليس مستنداً إنشائياً. الحفظ محلي في متصفحك فقط، واستخدم زر JSON لتصدير نسخة احتياطية.
